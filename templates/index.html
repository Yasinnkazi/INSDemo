What is SQL Injection?

SQL Injection is a code injection technique that exploits security vulnerabilities in an application's software by inserting malicious SQL statements into input fields. This project demonstrates both vulnerable and secure login systems to help students understand the importance of secure coding practices.

Project Features

  • Two login systems - Insecure vs Secure
  • Live SQL Injection demonstration
  • Real-time query visualization
  • Prevention using Prepared Statements
  • Session management and logout
  • Responsive dark theme design
